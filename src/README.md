# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Sign up for activities
- Share activity links with friends using built-in share, WhatsApp, and Facebook buttons

## Development Guide

For detailed setup and development instructions, please refer to our [Development Guide](../docs/how-to-develop.md).

## Using social sharing

Each activity card includes sharing buttons so students and teachers can quickly spread the word about an activity.

- **Share / Copy Link** opens the device share menu when available or copies a direct activity link
- **WhatsApp** opens a ready-to-send message with the activity details
- **Facebook** opens Facebook's share page for the activity link

Shared links include the selected activity in the page address so the activity is easy to find when a friend opens it.
